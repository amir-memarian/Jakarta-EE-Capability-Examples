Step 1: Prerequisites (Installing Tools)
-- JDK 17 (set JAVA_HOME)
-- IntelliJ IDEA (Ultimate or Community)
-- MySQL 8.0.31
-- Apache Tomcat 11 (Download and Extract)
-- Maven
-- Git (for push to GitHub)

Step 2: Create a project in IntelliJ IDEA
    New Project → Jakarta EE
    Settings:
        Name: jakarta-jpa-hibernate
        Language: Java
        Build system: Maven
        JDK: 17
        Template: Web application
    In the Dependencies section, add:
        Servlet
        JPA / Hibernate (we will complete it later in pom.xml)

Step 3: Set up pom.xml
    jakarta.persistence-api
    hibernate-core
    mysql-connector-java
    jakarta.servlet.jsp.jstl-api (optional)
    jakarta.servlet.jsp.jstl (optional)
    gson
    lombok
    junit-jupiter-api
    junit-jupiter-engine


Step 4: Create MySQL Database
    CREATE DATABASE bankdb;
    USE bankdb;
    -- (optional - Hibernate creates the tables itself)

Step 5: Configure Connection Pool in Tomcat or src/main/webapp/META-INF/context.xml
    Change $CATALINA-HOME/conf/context.xml
    <Context>
        <Resource name="jdbc/BankPool"
                  auth="Container"
                  type="javax.sql.DataSource"
                  driverClassName="com.mysql.cj.jdbc.Driver"
                  url="jdbc:mysql://localhost:3306/bankdb?useSSL=false&amp;serverTimezone=UTC"
                  username="root"
                  password="your_password_here"
                  maxTotal="20"
                  maxIdle="10"
                  maxWaitMillis="-1"/>
    </Context>
    Note: Replace your_password_here with your MySQL password.

Step 6: Change resources/META-INF/persistence.xml file
    <persistence-unit name="bankPU" transaction-type="RESOURCE_LOCAL">
        <provider>org.hibernate.jpa.HibernatePersistenceProvider</provider>
        <non-jta-data-source>java:comp/env/jdbc/BankPool</non-jta-data-source>
        <properties>
            <property name="jakarta.persistence.schema-generation.database.action" value="create"/>
            <property name="hibernate.dialect" value="org.hibernate.dialect.MySQL8Dialect"/>
            <property name="hibernate.show_sql" value="true"/>
            <property name="hibernate.format_sql" value="true"/>
        </properties>
    </persistence-unit>

Step 17: Build and Deploy on Tomcat
    Method 1: Using Maven (Generate WAR)
        cd jakarta-jpa-hibernate
        mvn clean package

        The WAR file will be created in target/jakarta-jpa-hibernate.war.
        Then:
        Copy the WAR file to {tomcat-home}/webapps/
        Run Tomcat: {tomcat-home}/bin/startup.sh (or .bat)

    Method 2: In IntelliJ IDEA
        Run → Edit Configurations
        Add Tomcat Server → Local
        In the Deployment tab:
        Click + → Artifact → Select jakarta-jpa-hibernate:war exploded
        Apply → OK
        Run (Shift+F10)

Step 18: Test the project
    http://localhost:8080/jakarta-jpa-hibernate/

tail -f {tomcat-home}/logs/catalina.out
