Step 1: Prerequisites (Installing Tools)
-- JDK 17 (set JAVA_HOME)
-- IntelliJ IDEA (Ultimate or Community)
-- MySQL 8.0.31
-- Apache Tomcat 11 (Download and Extract)
-- Maven
-- Git (for push to GitHub)

Step 2: Create a project in IntelliJ IDEA
    New Project → Jakarta EE
    Settings:
        Name: jakarta-jpa-hibernate
        Language: Java
        Build system: Maven
        JDK: 17
        Template: Web application
    In the Dependencies section, add:
        Servlet
        JPA / Hibernate (we will complete it later in pom.xml)

Step 3: Set up pom.xml

Step 4: Create MySQL Database
    CREATE DATABASE bankdb;
    USE bankdb;
    -- (optional - Hibernate creates the tables itself)

Step 5: Configure Connection Pool in Tomcat
    Change $CATALINA-HOME/conf/context.xml
    <Context>
        <Resource name="jdbc/BankPool"
                  auth="Container"
                  type="javax.sql.DataSource"
                  driverClassName="com.mysql.cj.jdbc.Driver"
                  url="jdbc:mysql://localhost:3306/bankdb?useSSL=false&amp;serverTimezone=UTC"
                  username="root"
                  password="your_password_here"
                  maxTotal="20"
                  maxIdle="10"
                  maxWaitMillis="-1"/>
    </Context>
    Note: Replace your_password_here with your MySQL password.

Step 11: Build and Deploy on Tomcat
    Method 1: Using Maven (Generate WAR)
        cd jakarta-jpa-hibernate
        mvn clean package

        The WAR file will be created in target/jakarta-jpa-hibernate.war.
        Then:
        Copy the WAR file to {tomcat-home}/webapps/
        Run Tomcat: {tomcat-home}/bin/startup.sh (or .bat)

    Method 2: In IntelliJ IDEA
        Run → Edit Configurations
        Add Tomcat Server → Local
        In the Deployment tab:
        Click + → Artifact → Select jakarta-jpa-hibernate:war exploded
        Apply → OK
        Run (Shift+F10)

Step 12: Test the project
    http://localhost:8080/jakarta-jpa-hibernate/customers

    CRUD operations:
    Create: Fill out the form and submit
    Read: Display all customers in the table
    Update: (Requires development in Servlet)
    Delete: By sending a DELETE request (with a tool like Postman)
    Postman:
    DELETE http://localhost:8080/jakarta-jpa-hibernate/customers?id=1
